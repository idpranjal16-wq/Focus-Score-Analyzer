🧠 FocusFlow
Measure your Day . Improve your Tomorrow.

FocusFlow is a simple productivity dashboard built with Python and Streamlit.

 Features

- 👤 Enter your name and today's goal
- 📝 Log your daily activities
- ⏰ Track hours spent
- 📊 Generate productivity reports
- 📈 Interactive charts
- 🎯 Focus Score
- 💡 Smart recommendations

 Tech Stack

- Python
- Streamlit
- Pandas
- Plotly

 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
